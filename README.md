# 🇮🇳 CivicPath

AI-powered platform for navigating Indian government procedures.

CivicPath converts complex government processes into simple, interactive step-by-step paths with required documents and dependencies.

### 🛠️ Tech Stack
React • Node.js • Express • MongoDB • AI

### ✨ Features
- Government procedure discovery
- Step-by-step guidance
- Document requirements
- Dependency mapping
- AI-powered assistance
